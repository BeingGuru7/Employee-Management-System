# Employee Management System

## 📌 Description
A full-stack Employee Management System built using Spring Boot and MySQL. It allows users to perform CRUD operations on employee data through REST APIs and a simple frontend interface.

## 🚀 Tech Stack
- Java (Spring Boot)
- MySQL
- HTML, CSS, JavaScript
- Git, Postman

## ✨ Features
- Add Employee
- View Employees
- Update Employee
- Delete Employee

## 📁 Project Structure

Employee-Management-System/
├── src (backend)
├── ems-frontend (UI)
